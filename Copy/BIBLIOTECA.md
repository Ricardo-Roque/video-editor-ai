# Biblioteca de copy

Os livros ficam na pasta local `Livros Copywriting/` (fora do Git, por direitos autorais). Cada obra lida vira um resumo aplicado em `Copy/livros/`, e o [COPY.md](COPY.md) junta tudo num método só para os nossos criativos.

**Status**: ✅ resumo pronto · ⏳ na fila · ➖ fora do escopo (não é sobre copy ou é duplicata)

Leitura concluída em 21/11/2026: 58 obras resumidas em 34 arquivos. Algumas obras parecidas dividem o mesmo resumo (por exemplo, os três livros de Maslen e os manuais complementares). Cada resumo diz no topo **como** a obra foi lida:
- **na íntegra**: os livros curtos e os principais;
- **capítulos centrais**: os livros longos;
- **por tema**: as coletâneas enormes, como o arquivo de 3.891 páginas de Makepeace.

Arquivos escaneados (sem texto) passaram por OCR do Windows; citações deles podem ter pequenos erros de leitura.

**Livro novo**: coloque o PDF em `Livros Copywriting/`, peça ao Claude para lê-lo, criar o resumo em `Copy/livros/` no mesmo formato (o que é, ideia central, como usar nos nossos criativos, cuidados, frases), acrescentar uma linha aqui e atualizar o [COPY.md](COPY.md) se trouxer algo novo.
