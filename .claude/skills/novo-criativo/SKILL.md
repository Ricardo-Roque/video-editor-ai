# Novo criativo

1. Read `PROCESSO.md`, `CLAUDE.md` and `PRODUTOS.md` at the project root. They are the source of truth for every step, tool command, naming convention, product fact and rule.
2. `Criativos Exemplo/` has one folder per format (all 16 from the team's Trello board), each with a `FORMATO.md` guide (why it holds attention, how to write the script, how to produce it here, cost, risks) plus the delivered creatives in that format. Formats are the 16 from the team's Trello board, summarised in `FORMATOS.md` together with script structures and attention elements. Work out which format and script structure the reference follows; read that format's `FORMATO.md` and flag any missing tool it mentions before spending; in the analysis, annotate every line of the reference with the attention elements from `FORMATOS.md` (the map the translation must preserve); for a new script built from a winning creative, follow Etapa 2b in `PROCESSO.md`; and use the example folders (analise, prompts, takes_config, montagem.json, production notes) as the template. `CRIATIVOS.md` is the catalog with costs and lessons.
3. Identify the creative:
   - New: ask only for what is missing among: creative number (`Criativo NN`, the next free folder number, not the reference file's number), reference file in `Vídeo Bruto/`, target language, target country, product (and whether packaging or claims change), and whether the format follows the reference or another one. Then do Etapa 0 (copy `_Modelo Criativo/` into `Criativo NN/` at the project root, where creatives stay while in production; check that the video model is up).
   - Existing: open `Criativo NN/` (at the root if in production, in `Criativos Exemplo/<format>/` if delivered) and work out the current stage from the files present (analise.md, roteiro, imagens, takes, montagem) and the "Notas de produção" in the roteiro. Tell the user where it stands and what comes next. If images or takes are missing because media is not in Git, ask the user to copy them from the team's shared folder.
4. Run the next stage exactly as PROCESSO.md describes, then stop at its approval gate and present the result in Portuguese (with back-translation of any foreign-language text, costs estimated before and spent after).
5. When the creative is delivered, follow "Ao entregar um criativo" in `PROCESSO.md`: production notes; move the folder into `Criativos Exemplo/<format>/` and change the `../` output and font paths in its `montagem*.json` to `../../../` (first creative of a format: add its examples table and lessons to that `FORMATO.md`); update `CRIATIVOS.md` and the `FORMATO.md`; record new product facts in `PRODUTOS.md`; document new tools in `PROCESSO.md`; then offer to commit and push.
